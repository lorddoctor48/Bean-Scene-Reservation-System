# Project-Assessment-Bean-Scene-Reservation-System

### Developed by Lloyd Ryu

## Overview
Diploma of Information Technology (Advanced Programming) Mobile Application Development Cluster

The Bean Scene Reservation System is an ASP.NET MVC application to be used by the restaurant and customers to make a booking for reservation within a sitting (breakfast, lunch, dinner, special event, and others). It is integrated with the SQL Server database through Entity Framework to store data relating to reservations, sittings, and users.

## Features

### Multi-channel Reservation Capture
- Web
- In-person
- Phone
- Email

### Record customer details 
- Name
- Contact information
- Special requests 

### Sitting management 
- Type
- Time
- Capacity
- Availability

### Reservation status updates 
- Pending
- Confirmed
- Cancelled 
- Seated
- Completed

### Tale and are assignment 
- Main 
- Outside
- Balcony

### Authentication and authorisation 
- Member registration 
- Login for guests 
- Staff and manager login

### Generate reports 
- Number of bookings
- Cancellations
- Table utilisation
- Reservation source reporting
